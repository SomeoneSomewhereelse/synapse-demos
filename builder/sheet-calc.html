Spreadsheet calculations task

The participant downloads an orders and stock spreadsheet, opens it in their own spreadsheet program, adds a Total column, a SUM of it and a Yes/No "Low stock" column, all as formulas, and uploads it back to be checked. Below is the real task from the build, running in the page.

  • Pick a level, a version (workplace) and a language.
  • Download the file, change it in Excel, Google Sheets, LibreOffice or Numbers, save it as .xlsx and upload it back.
  • Or send one of the ready-made files for a quick look.
  • Press the check button to see the verdict, then open the answer key.

What is checked

  • Columns A–E and the rows came back as handed out (headings and items in either language; a sum row and new columns are fine).
  • Every Total is right, to the cent, and calculated.
  • The SUM is right and is a SUM(…) formula.
  • Every row says Yes or No (כן / לא) correctly, by formula. An item exactly at its minimum is not low.
  • A typed number, or a formula over plain numbers like =SUM(695.2), counts as typed.

Try the unexpected

  • Some totals as formulas, some typed.
  • TRUE/FALSE instead of Yes/No.
  • Format the data as a table (formulas like [@Qty]), or use its Total Row.
  • A named range, the SUM beside the table, or a count under it.
  • Insert a column between A and E, sort, or delete a row.
  • Save as .xls, .csv or .ods; upload another level's file.

How it fits sessions

  • Three task ids, m22–m24, one level each; a session holds at most one of them.
  • "Quick start" (the default six, no Excel) is now the first option in "Level and tasks".
  • "Easy" now includes the easy level of this task.
  • Never in the random draw, the free trial or the default setup; a test now fails if it gets there.
  • Presentation mode shows one card with Easy / Medium / Hard.
